# 원본 PDF와 기존 MD의 차이

기준: `C:/Users/LG/Downloads/track-2-marketing-agent (1).pdf` 1~6쪽. 비교 대상: 수정 전 `C:/Users/LG/Downloads/track-2-marketing-agent.md`. **PDF가 최상위 요구사항**이다. 기존 MD는 PDF의 단순 축약본이 아니라 다른 과제를 서술했다.

| 항목 | PDF 원본 | 수정 전 MD | 정렬 결정 |
|---|---|---|---|
| 핵심 제출물 | 심사자 **Mac**에서 실행되는 **localhost 3칸 대시보드** + 2~3분 시연 | 백그라운드 CLI 에이전트, 3분 내외 시연 | 대시보드가 필수. CLI는 내부 도구일 수 있어도 제출물의 대체물이 아님. |
| ① 입력 | 지정된 **우리 채널 5개**의 최신 영상 목록, 썸네일·제목·채널·날짜. API 키 없이 불러오기 가능 | 연애 키워드로 30분마다 최근 12시간 영상 자동 탐지 | 5채널 목록을 필수로, 키워드 탐지를 가점으로 이동. |
| ② 선택·초안 | 사용자가 영상을 고르면 고민 한 줄·댓글 초안 표시. 제출 시점 최신 영상 초안을 `drafts/`에 미리 포함 | 자동 판별·조회수 트리거 후 댓글 생성, 사전 초안 없음 | 선택 UI와 키 없는 저장 초안을 필수로 추가. |
| 브랜드·댓글 | ‘운명원’을 자연스럽게 궁금하게 함. 링크·해시태그·**이용해 본 것처럼 지어낸 후기** 금지 | ‘연애사주를 봤던 경험’ 댓글, 링크 금지 | 허위 경험담을 삭제하고 브랜드·해시태그 금지를 추가. |
| ③ 게시 제어 | **심사자가 버튼을 누른 뒤** 지정 프로필이 열려 화면에 보이게 한 글자씩 입력·게시·확인 | 정해진 주기마다 자동 게시, 기존 CDP Chrome에 연결 | 사람의 명시적 클릭을 필수 게이트로, 프로필 폴더 지정 실행을 설계. |
| 게시 범위 | 우리 채널 5개 **및** 본인 테스트 영상. 우리 채널은 개발 중 미리 게시 금지 | 본인 테스트 영상 allowlist에만 게시, 우리 채널은 항상 dry-run | 심사자 실행 시 우리 채널 게시 허용, 개발 중에는 본인 테스트 영상만 사용. |
| 프로필 | 유튜브1 한 개 필수, 유튜브1~3 배정 가점 | 로그인된 Chrome CDP 세션 한 개 | 유튜브1 프로필 실행을 필수, 나머지를 가점으로 이동. |
| 안전 규칙 | 쿠키·비밀번호·브라우저 저장 정보 읽기/저장 금지, 폴더 밖 파일 읽기 금지, YouTube·AI 이외 송신 금지, 허용 페이지 외 열기 금지 | 키·쿠키의 저장소 업로드 방지 위주 | PDF의 **실행 중** 금지 행위를 별도 코드·검증 항목으로 추가. |

## 현재 구현과의 관계

`D:/projects/샘플_폴더/샘플프로젝트/marketing_agent`는 수정 전 MD를 기준으로 만든 CLI다. 현재 README와 코드에는 3칸 localhost 대시보드, 지정 5채널 RSS 목록, 제출 시점의 `drafts/`, 심사자 버튼으로 여는 Mac 크롬 프로필, 한 글자씩 보이는 입력이 없다. 따라서 **PDF 기준 제출물로 완료 판정할 수 없다.** 이 문서 정렬은 코드 구현 완료를 뜻하지 않는다.
