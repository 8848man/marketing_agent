# ADR-0002 — 로컬 위협 모델: "심사자 1인의 Mac, 같은 OS 사용자는 신뢰 경계 안"

> 상태 **제안**. 사용자 확인 후 `accepted`로 바꾼다. 확정 전까지 SEC-01·SEC-05는 "부분"으로 둔다.

## 맥락

개선 계획 P0-1(로컬 서버 접근)과 P1-4(파일 경계)는 "같은 PC의 다른 프로세스"까지 막는 설계를 요구한다. 그러나 PDF가 상정하는 실행 환경은 심사자가 자기 Mac에서 직접 내려받아 실행하는 단일 사용자 앱이고, 같은 OS 사용자 권한의 악성 프로세스는 이미 앱 폴더·Chrome 프로필·`.env`를 직접 읽을 수 있다. 이 위협을 localhost 토큰으로 막으려는 작업은 비용 대비 효과가 낮고 과제 배점(안전 규칙 15점)의 판정 기준도 아니다.

## 결정(제안)

1. **신뢰 경계 안:** 앱을 실행한 OS 사용자와 그 사용자의 프로세스.
2. **경계 밖(막아야 함):** 원격 웹사이트(브라우저 CSRF·DNS rebinding), 다른 OS 사용자, 네트워크의 다른 기기.
3. 현재 방어(127.0.0.1 바인딩, Host·Origin·세션 토큰 검사, 민감 GET 토큰, 캡처 파일 크기·심볼릭 링크 검사)로 2번을 충족한다고 본다.
4. SEC-01(같은 PC 프로세스 인증)과 SEC-05(검사 후 교체 경쟁)는 **수용한 위험**으로 기록하고 추가 구현하지 않는다.

## 결과

- 개선 계획의 P0-1·P1-4는 "위협 모델로 종결(수용)" 판정이 된다.
- 다중 사용자 PC나 서버 배포로 범위가 바뀌면 이 ADR을 대체하는 새 ADR이 필요하다.
