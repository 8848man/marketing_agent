## 시험 기록 양식

각 관문·수락 시험마다 아래 항목을 채워 `checklist.md`의 해당 행과 연결한다.

```text
시험 ID / PDF 요구 ID:
실행 날짜·환경(Mac/Chrome/Python/Playwright 버전):
실행 명령·입력(비밀 제외):
기대 결과 / 실제 결과:
증거 파일 또는 링크(대시보드 폴더 안, 비밀 제거):
실패 원인·다음 결정:
검토자:
```

기존 Windows/모의 브라우저 테스트 `70 passed`는 회귀 기준으로만 적는다. 위 표의 어떤 Mac 수락 시험도 이를 근거로 완료 표시하지 않는다.

### U26~U28 추가 검증 (2026-10-16)

모의 시험에서 프로필별 확인 이메일의 메모리 생존/실패 초기화, 허용 영상·HTTP 경계, .env 키 이전 및 재시작, 라운드 로빈 배정 1→2→3→1→2, 생성 JavaScript 문법을 확인했다. 실제 한국어 YouTube의 허용 영상 `QXmBHgPqEUE`에서 유튜브1의 계정 전환 메뉴에 표시된 이메일을 읽기 전용으로 확인했다(값은 출력하지 않음). 댓글 입력·게시·계정 전환 클릭은 수행하지 않았다. 다중 프로필 계정/카드 상태 실환경 확인과 Mac G2는 남는다.

### U29 추가 검증 (2026-10-16)

로그인 창 설정 API의 미등록 영상 거부와 불러온 허용 영상 URL 전달, 게시 예약 0회를 모의 시험했다(관련 3개 통과). 생성 대시보드 JavaScript 문법도 통과했다. 실제 `로그인 창 열기` 버튼의 영상 화면 표시는 현장 시각 검증을 남긴다.

### U30 추가 검증 (2026-10-16)

공식 Google `ServiceLogin`이 Google 계정 로그인 화면으로 연결되는 것을 확인했다. 앱 전용 Chrome 실행 인수의 마지막 URL이 고정 로그인 주소이고, 영상 ID 없이도 프로필 준비가 가능하며 HTTP의 추가 영상/URL 필드가 거부됨을 모의 시험했다(관련 4개 통과). 계정 자격 증명 입력과 실제 로그인 완료는 앱 코드가 수행하지 않는다.

### U31 추가 검증 (2026-10-16)

허용/비허용 채널이 섞인 RSS에서 허용 영상만 고르고 요청한 앱 전용 프로필로 확인하며, 선택 목록·배정 DB를 변경하지 않는 모의 시험을 추가했다. 실제 재시작 뒤 RSS가 비어 `PROFILE_EMAIL_VIDEO_UNAVAILABLE`이 반환되어, 기존 허용 채널의 `POSTED` 영상만 읽기 전용 대안으로 추가했다. 비허용 채널의 더 최신 게시 기록을 건너뛰는 모의 시험을 통과했다. 대시보드 회귀 33개와 생성 JavaScript 문법 검사를 통과했다. 실제 유튜브1에서 허용 영상의 계정 메뉴를 읽어 HTTP 200과 이메일·확인 시각 존재를 값 비노출로 확인했다. 실제 Google 로그인 창 종료 뒤 자동 확인 결과가 UI에 표시되는 현장 수락은 남긴다.

### U32 추가 검증 (2026-10-16)

기존 Gemini 키를 앱 데이터 파일에서 루트 `.env`로 이전하고 이전 파일을 제거하는 모의 시험, 이전 실패 시 원본 보존, 네 AI 제공사 키 독립 선택/삭제, YouTube 변수 보존, 누락 키 409를 확인했다. 전체 모의 회귀 140개 통과. 실제 서버 재시작 후 루트 `.env` 생성, 이전 파일 제거, `/api/ai`의 Gemini 키 존재 표시를 확인했다. 실제 키 값은 검증 출력에 남기지 않았다.

### U33 추가 검증 (2026-10-16)

생성 HTML의 JavaScript 문법 검사와 전체 pytest 140개 통과. 임시 로컬 헤드리스 Chrome에서 초안 없는 영상의 중립 문구, 안내형 비활성 게시 버튼의 토스트, 게시 호출 0회를 확인했다. 키 없는 AI 초안 버튼의 설정 경로 토스트와 AI 호출 0회를 확인했다. 별도 모의 프로필 서비스에서 `유튜브2`의 `현재 계정 확인`이 유튜브2 레이블을 열고 창 종료 뒤 `/api/profile/verify-email` 및 YouTube 요청이 0회인 것을 확인했다. 실제 Google AccountChooser 화면과 유튜브2의 직접 로그인은 사용자 환경 수락으로 남긴다.
