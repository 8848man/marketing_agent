## PDF 수락과 운영

- [ ] 다른 Mac에서 README만으로 10분 안에 3칸 대시보드 실행. 시각·Mac 버전·화면 캡처 필요.
- [ ] 지정 5채널 최신 영상의 썸네일·제목·채널·게시 날짜 실측과 제출 직전 재확인.
- [ ] 각 최신 영상의 자막 우선·대체 자료·인기 댓글 근거와 40~120자 사람 승인 초안 `drafts/` 포함. 허위 후기·링크·해시태그·복제 댓글 검토.
- [ ] 선택만으로 Chrome/게시 0회, 게시 직전 채널·승인본·중복·하루 10개 재검증, 동시 클릭·재시작 시험.
- [ ] 본인 테스트 영상에서만 유튜브1 보이는 Chrome, 글자별 입력, 게시, 내 댓글 확인, 실패 캡처와 시간순 기록을 Mac 한국어 YouTube에서 검증.
- [ ] 게시 전 확정 실패와 게시 후 결과 불명확을 구분하고 불명확 결과의 자동 재게시 0회 확인.
- [ ] 쿠키·비밀번호·브라우저 저장 정보 직접 읽기/저장 0건, AI 키 노출 0건, 허용 외 페이지·댓글 외 조작·허용 외 송신 0건을 코드와 실행 기록으로 검증.
- [ ] 우리 채널 5개 영상의 개발 중 사전 게시 0건 확인. 본인 테스트 영상의 2~3분 시연 원본과 접근 가능한 링크 확보.
- [ ] Public 저장소 공개와 외부 제출 전 결과·비밀정보·링크를 사용자에게 제시하고 **최종 승인** 받기. 현재 공개·제출하지 않음.

완료 처리 시 시험 날짜, 환경, 실제 명령, 영상 ID, 캡처/로그 위치, 검토자와 결과를 함께 남긴다. `validation-protocol.md`의 V1~V6 수락 시험도 모두 미완료다.
