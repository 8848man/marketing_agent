## 지원자가 제공해야 할 환경·증거

### 2026-10-15 로컬 시험 보완

기본 게시 경로는 그대로 두고 `dashboard --demo`를 추가해 Windows에서 ① 가상 영상 → ② 예시 초안 → ③ 모의 클릭을 확인할 수 있게 했다. 데모는 YouTube·게시용 Chrome 프로필·게시 DB에 접근하지 않고 `DEMO_NO_POST`로 끝난다. pytest 설정 함수 이름 충돌을 고쳐 전체 99개 시험이 통과했다. G3의 잘못된 Host·Origin·토큰 요청은 임시 SQLite 예약 0건·게시 함수 0회로 확인했다. 본인 테스트 영상은 소유 자료 파일과 저장된 영상/채널/제목이 맞을 때만 게시 후보로 연결했다. 실제 소유권과 Mac 게시는 미검증이다. 이 기록은 T05·T08·T09·T11·T12 또는 Mac G2의 완료 표시가 아니다.

후속 보완: 본인 테스트 영상도 선택 시와 게시 요청 시 채널 RSS에서 영상 ID·채널 ID·제목을 재확인한다. 조회 오류, 피드 항목 부재, 등록 제목 불일치 시 게시를 막고 한국어 이유를 보여 준다. 해당 실패에서 게시 예약과 Chrome 호출이 0회인지 시험했다. RSS 최근 목록 밖 영상은 안전한 별도 검증 경로가 아직 없어 게시할 수 없다. 사용자 제공 영상 `onotxd-Ziag`와 채널 `UCyeBugylmxXJzSp6y7YycUw`의 실제 일치 여부는 현재 네트워크 조회 실패로 미검증이다. 전체 회귀 시험은 103개 통과로 갱신한다.
