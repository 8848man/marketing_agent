## 현재 상태와 다음 증거

Windows에서는 3단계 대시보드, 옵션의 채널/AI API 관리 UI, 오프라인 데모와 회귀 시험 108개가 확인됐다. 네 AI 제공사의 모의 호출과 키 비노출/요청 거부를 시험했다. G3의 거부 요청에서 예약과 게시 함수 호출이 0회인 시험도 있다. 실제 AI 키 호출, Mac 실환경, 실제 YouTube 게시 통과는 아직 확인하지 못했다.

Windows에서 G1 다섯 채널의 실제 RSS 응답을 확인하고 파서를 수정해 채널별 최신 영상 15개를 읽었다. 연결 테스트 UI의 재확인과 게시 직전 재조회, 각 최신 영상의 사람 승인 초안, G2의 Mac `유튜브1` 프로필·로그인·잠금·한국어 댓글 화면, 본인 테스트 영상 실게시와 시연 증거가 남아 있다. 결과는 `validation-protocol.md`와 `checklist.md`에 기록하고 모두 확인되기 전에는 기능을 완료로 표시하지 않는다.

- U16 현재 구현: 앱 전용 Chrome 프로필 유튜브1~3의 목록 선택과 로그인 필요 시 같은 프로필의 수동 로그인·명시적 재개. 실제 복수 계정과 Mac 검증은 남았다.

- U17 현재 구현: 성공한 댓글 화면의 Chrome 창 유지 옵션, 프로필별 수동 이메일 표시와 Windows 사용자 암호화 저장. 실제 화면 유지 및 Mac 저장은 미검증이다.

- U18~U25 계획: 공유 영상 카탈로그와 프로필별 페르소나, 영상마다 고정되는 순환 자동 배정, 담당 영상의 게시 파랑/AI 초안 초록 상태를 명세했다. 영상 ID 전역 댓글 1개를 유지한다. 코드·실환경 수락은 아직 없다.

- U26~U28 현재 구현 (2026-10-16): 프로필 목록의 수동 이메일 저장·선택 버튼을 제거했다. 확인된 이메일은 앱 서버 메모리와 확인 시각에만 표시한다. 한국어 YouTube의 현재 계정 헤더에는 핸들만 있어, 허용 watch 페이지의 계정 전환 메뉴에 보이는 Google 계정 헤더 이메일을 읽고 페이지를 벗어나지 않는다. 실제 유튜브1에서 이메일을 읽기 전용으로 확인했다. 영상별 영속 순환 배정과 담당·상태 카드 색은 구현했으나 이전 기획의 프로필별 페르소나/공유 카탈로그 마이그레이션은 아직 남았다. AI 키는 실제 `config.yaml`에서 `data/dashboard/.env`로 이전했고, YAML 키 필드가 제거됐으며 서버 재시작 후 자격 정보를 읽는다. 전체 모의 시험 135개 통과.

- U29 구현 (2026-10-16): 로그인 준비 Chrome은 불러온 허용 영상의 watch URL로 시작하고 목록이 없으면 UI에서 영상 불러오기를 안내한다. 프로필의 게시 담당 여부와 무관하게 허용 영상 페이지에서 수동 로그인할 수 있다. 임의 영상/허용 외 채널은 서버에서 차단한다. 실제 Chrome 버튼 클릭은 아직 시각 검증 전이다.

- U30 구현 (2026-10-16): 로그인 준비는 YouTube 영상과 분리되어 앱 전용 Chrome에서 Google `ServiceLogin`을 직접 연다. 사용자 요청에 따라 이전 U29 흐름을 대체한다. 설정 요청은 프로필 레이블만 받고 URL을 수용하지 않는다. 4개 관련 회귀와 JS 문법 통과.
- U31 구현 (2026-10-16): 앱이 연 로그인 Chrome 창을 닫으면 현재 YouTube 사용 계정을 허용 영상에서 읽기 전용으로 확인해 프로필 이름 옆에 표시한다. 계정 확인은 댓글 담당/영상 선택과 독립적이며 수동 재확인도 가능하다. RSS가 실패하면 기존 허용 채널의 게시 확인 완료 영상을 확인용으로 재사용한다. 계정 값은 서버 메모리에만 두고 실제 로그인 후 화면 수락은 남긴다.
- U32 구현 (2026-10-16): AI 키 파일을 프로젝트 루트 `.env`로 옮기고 `.env.example`에 OpenAI·Gemini·Anthropic·xAI 변수 이름을 명시했다. 기존 데이터 폴더/YAML 키를 이전하며 제공사별 키는 독립적으로 보존한다. 선택한 제공사 키가 없으면 AI 호출 전에 409 오류를 낸다.
- U33 구현 (2026-10-16): 초안 없음은 오류 대신 생성·승인 안내로 표시한다. 비활성 버튼은 클릭/키보드로 토스트를 보여 주되 요청을 차단한다. 프로필의 계정 확인과 로그인 창은 각 분리 루트의 Google 계정 선택 화면을 열며 창 종료 뒤 YouTube를 자동으로 열지 않는다. 실제 Google 로그인 화면 수락은 남는다.
- U34 구현 (2026-10-16): 초안 생성의 인기 댓글 조회는 루트 `.env`의 `YOUTUBE_API_KEY`를 요청마다 읽는다. 키가 없으면 환경변수를 대체 경로로 쓰고, 조회 실패는 키 누락과 별도로 안내한다. 모의 댓글 요청 및 전체 141개 회귀가 통과했다.
- U35 구현/U36 계획 (2026-10-16): 채널 관리에서 이름과 선택 ID를 함께 다루며 이름 검색 후보를 사람이 고른 뒤 RSS로 확인한다. 이름·ID는 함께 저장되고 고급 설정 UI는 제거됐다. 전체 회귀 143개 통과. 프로필 단일 계정 확인 UX는 로그인/로그아웃/불확실 판정과 실제 한국어 YouTube 수락 기준까지 문서화했으며 구현 전이다.
- U35 정정/U36 구현/U37 프로필 확장 (2026-10-16): 채널은 ID 필수·이름 선택이며 RSS만 연결 시험한다. 프로필은 실제 YouTube 화면 기반 로그인/로그아웃/확인 불가 판정과 단일 버튼 흐름으로 바뀌었다. 이름으로 최대 20개 전용 프로필을 추가하고 세 행 높이 목록에서 스크롤한다. 전체 회귀 144개 통과. 한국어 YouTube 실제 로그인 상태 수락은 남는다.
