# drafts/ — 제출용 댓글 초안

PDF(5쪽)는 심사자 컴퓨터에 AI 키가 없어도 쓸 수 있도록 **제출 시점 우리 채널 최신 영상의 고민 한 줄·댓글 초안**을 이 폴더에 넣으라고 요구한다.

- 파일: `<video_id>.json` (영상 1개당 1개). 필드는 `video_id`, `channel_id`, `title`, `worry_summary`, `cited_detail`, `source_text`, `comment` 등.
- **두 가지 상태가 함께 들어 있다.**
  - 승인됨: `approval_hash`가 내용 해시와 같고 `reviewer`·`reviewed_at`이 있다(검토자 표기는 샘플 이름 `아무개`). 바로 게시할 수 있다.
  - 승인 전: AI가 만든 초안(`generated_at`)이며 아직 사람 승인이 없다. 대시보드 ② 검토·승인 화면에서 문안을 읽고 승인해야 게시할 수 있다. 심사 모드는 이 중 하나를 '테스트용'으로 맨 위에 보여 준다.
- 대시보드는 선택·게시 직전에 영상 ID·채널·제목·승인 해시와 품질 규칙(40~120자, 링크·해시태그 금지, 근거 인용, 브랜드 고유명사·허위 후기·부정 프레이밍 금지)을 다시 검사한다. 하나라도 어긋나면 게시 버튼이 막힌다.
- 커밋 기준: 채널별 최신 영상 초안 중 **현재 품질 검사를 통과한 것만** 넣는다. 품질 검사에 걸린 예전 초안과 `latest.json`은 넣지 않는다.
- 우리 채널 영상에는 개발 중 게시하지 않는다. 실제 게시는 심사자가 누른다.
