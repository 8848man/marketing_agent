# drafts/ — 제출용 사전 승인 초안

PDF(5쪽)는 심사자 Mac에 AI 키가 없어도 보이도록 **제출 시점 우리 채널 최신 영상의 고민 한 줄·댓글 초안**을 이 폴더에 넣으라고 요구한다.

- 파일: `<video_id>.json` (영상 1개당 1개). 필드는 `video_id`, `channel_id`, `title`, `worry_summary`, `cited_detail`, `source_text`, `comment`, `reviewer`, `reviewed_at`, `content_hash`, `approval_hash` 등.
- 대시보드는 선택·게시 직전에 영상 ID·채널·제목·승인 해시와 품질 규칙(40~120자, 링크·해시태그 금지, 근거 인용, 브랜드 고유명사·허위 후기·부정 프레이밍 금지)을 다시 검사한다. 하나라도 어긋나면 게시 버튼이 막힌다.
- 제출 직전 절차: ① 영상 불러오기로 5채널 최신 영상 확인 → ② 각 영상 AI 초안 생성(`draft-v5` 이상) → ③ 사람이 읽고 고쳐 승인 → ④ 이 폴더의 승인본만 커밋. 오래된 영상·미승인 파일은 커밋하지 않는다.
- 우리 채널 영상에는 개발 중 게시하지 않는다. 실제 게시는 심사자가 누른다.
