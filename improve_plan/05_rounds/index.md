## 라운드 파일 공통 구성

1. 목표 — 라운드가 끝나면 달라지는 것
2. 작업 목록 — ID, 내용, 대상 위험, 상태
3. 작업 계약서 — 계획 단계에서 채움 (150줄을 넘으면 `roundN_…/` 폴더로 분리)
4. 결정 필요 사항
5. 게이트 판정 — 라운드 종료 시 기록
