## 검증 장치가 실제로 잡아낸 문제

| 잡은 곳 | 문제 | 결과 |
| --- | --- | --- |
| 검토 에이전트 | 게이트 도구가 파일 이동을 놓쳐 허용 밖 변경을 통과시킴 | `--no-renames` 수정 |
| 검토 에이전트 | 패키징 금지 검사가 대소문자를 구분(Windows·Mac에서 `Data/`·`.ENV` 통과) | 대소문자 무시 |
| 검토 에이전트 | 오탐 수정이 오히려 한글 뒤 이메일을 놓치게 만듦 | 정규식 재수정 |
| 메인 정독 | `.env`에 새 키를 넣어도 무시되고 지워짐, 깨진 키 저장소로 앱이 시작 안 됨 | 재작업 |
| 검토 에이전트 | 채널 간격 안내가 화면에 안 나옴, 일시 오류에도 키 저장소 격리 | 수정 |
| 메인 설계 | 락만 줄이면 게시 중 다른 계정으로 전환될 수 있음 | 브라우저 락 분리 |
| 게이트(간헐 실패) | 요청 ID가 숫자로 시작하면 62% 확률로 로그에 `INVALID` | 수정 |
| 경계 시험 | 제품 `drafts.py`가 레거시 `writer`·`classifier`를 끌어옴 | 상수 이동(D-019) |
| 메인 검증 | 사용자 DB 테이블 재구성·스키마 승격 | 이전 버전 DB 3종으로 보존 확인 |
