# 보고 양식

하위 에이전트는 아래 양식 그대로 보고합니다. 양식을 벗어난 보고는 게이트 G0 실패로 처리합니다.

## 구현 보고

```markdown
## 구현 보고 RN-TM
- 결과: 완료 | 부분 완료 | 실패
- 커밋: <해시> <메시지>
- 변경 파일: <경로 목록>
- 추가·수정한 테스트: <테스트 이름 목록>
- 실패 확인: <명령> → <실패 출력 마지막 5줄>
- 통과 확인: <명령> → <통과 출력 마지막 5줄>
- 계약서와 다르게 한 점: <없음 | 항목과 이유>
- 확신이 없는 점: <없음 | 항목>
- 열지 않은 비밀 파일 확인: 예
```

## 검토 보고

```markdown
## 검토 보고 라운드 N
- 검토 범위: main...<브랜치> (<커밋 수>개 커밋)
- 차단 지적: <건수>
- 권고 지적: <건수>

| # | 등급 | 작업 ID | 파일:줄 | 문제 | 근거 | 제안 |
| --- | --- | --- | --- | --- | --- | --- |

- 체크리스트 항목별 결과: <항목: 통과 | 지적 # | 확인 불가(이유)>
- 확신 없음으로 표시한 지적: <번호 목록>
```

## 메인이 보고를 다루는 방법

- "통과 확인" 출력은 메인이 같은 명령을 다시 실행해 대조합니다.
- "계약서와 다르게 한 점"이 있으면 게이트와 별개로 메인이 그 부분의 diff를 읽고 승인 여부를 정합니다.
- "확신이 없는 점"은 검토 에이전트 프롬프트에 중점 확인 항목으로 넘깁니다.
