# 00. 문서 작성 규칙

## 1. 주제 단위 분리

- 한 파일은 한 주제만 다룹니다.
- 파일명은 `NN_주제.md` 형식입니다. `NN`은 읽는 순서입니다.

## 2. 150줄 규칙

- 파일 하나가 **150줄을 넘으면** 같은 이름의 폴더로 바꿉니다.
  - `03_roadmap.md` → `03_roadmap/index.md` + 하위 주제 파일들
- 폴더 안에서도 같은 규칙을 재귀적으로 적용합니다.
- 줄 수는 빈 줄을 포함한 실제 줄 수입니다.

## 3. 인덱스 규칙

- 모든 폴더에는 `index.md`가 있어야 합니다. (최상위는 `README.md`)
- 인덱스는 같은 폴더의 **모든 파일과 하위 폴더**를 링크합니다.
- 각 링크 옆에는 한 줄 설명을 붙입니다.
- 하위 폴더는 그 폴더의 `index.md`로 링크합니다.

## 4. 상태 표기

라운드·작업의 상태는 아래 값만 씁니다.

| 값 | 뜻 |
| --- | --- |
| 대기 | 아직 착수하지 않음 |
| 계획 | 계획 단계 진행 중 또는 승인 대기 |
| 구현 | 구현 에이전트 작업 중 |
| 검토 | 검토 에이전트 작업 중 |
| 완료 | 게이트 통과 |
| 보류 | 결정이 필요해 멈춤 (사유를 함께 적음) |

## 5. 근거 표기

- **[코드 확인]**: 현재 저장소 코드에서 직접 확인한 사실
- **[보고서]**: 분석 보고서에 근거, 현재 코드에서 재확인 전
- **[추정]**: 구조로부터 추론한 것

## 6. 검사

규칙 위반은 `tools/check_structure.py`가 찾아냅니다. 문서를 고친 뒤에는 실행해서 위반 0건을 확인합니다.
